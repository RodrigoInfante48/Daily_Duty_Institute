# 📁 Content — Convención de archivos

Todo el contenido de marketing generado vive aquí, organizado por canal.

## Naming convention

```
YYYY-MM-DD_[producto]_[descripción-corta].md
```

**Ejemplos:**
- `2026-04-15_datapocket_anamnesis-reel.md`
- `2026-04-15_kanbanpro_linkedin-six-sigma.md`
- `2026-04-15_datapocket_nurturing-sequence.md`

## Carpetas

| Carpeta | Canal | Formato |
|:--------|:------|:--------|
| `reels/` | Instagram Reels, TikTok | Scripts de video vertical |
| `linkedin/` | LinkedIn | Posts de texto |
| `email-sequences/` | Email | Secuencias de nurturing/post-compra |
| `whatsapp/` | WhatsApp | Templates de mensajes |
| `vsl/` | YouTube, Landing | Scripts de Video Sales Letter |

## Workflow

1. Claude genera contenido usando el skill `kanbanpro-brand`
2. Se guarda aquí con la convención de nombres
3. Se revisa y aprueba
4. Se publica en el canal correspondiente
