# DataPocket — Mensaje de Follow-Up (WhatsApp)

> **Contexto:** Para usar 48 horas después del primer contacto si no hubo respuesta, o después de una conversación inicial que quedó sin cierre.
>
> **Reglas del canal:** Máximo 4 líneas. No insistir en la venta directamente. Dar valor o bajar la fricción. Un solo intento de follow-up.

---

## Versión A — Si no respondió el primer mensaje (48h después)

```
Hola [Nombre],

Sé que estás ocupado — así que voy al punto:

¿Querés que te mande un video de 90 segundos que muestra exactamente cómo funciona DataPocket con una clínica dental real?

Sin compromiso. Solo para que lo veas.
```

---

## Versión B — Si hubo conversación pero no cerró (24-48h después)

```
[Nombre], ¿pudiste revisar lo que te conté ayer sobre DataPocket?

Me quedé pensando en los [X consultas/semana que mencionaste] — eso son [X] horas semanales de anamnesis manual.

Si querés verlo funcionando antes de decidir, te armo un demo rápido de 15 minutos. ¿Esta semana te viene bien?
```

---

## Versión C — Si pidió "pensar" / "consultarlo"

```
[Nombre], ¿pudiste hablarlo?

Si surgió alguna duda técnica o querés que te muestre cómo quedaría configurado para tu clínica específicamente — decime, lo hacemos en 15 minutos.

No hay ningún compromiso de compra para el demo.
```

```

Una clínica en Bogotá con 3 odontólogos recuperó 45 horas en el primer mes con DataPocket.

¿Te parece si te mando el caso completo para que lo evalúes?

```

## Respuesta a "¿Funciona para clínica médica además de dental?"

```
Sí — el stack funciona para cualquier especialidad que tenga formularios de ingreso de pacientes.

DataPocket está optimizado para odontología (las preguntas de anamnesis, las alertas clínicas, las instrucciones post-op).

Para otras especialidades médicas hay que personalizar el formulario y el prompt de Gemini — eso lo incluye el Setup Completo.

¿De qué especialidad es tu clínica?
```

## Reglas de cierre

**Cuándo parar:**
- Después de 2 follow-ups sin respuesta — no insistir más
- Si dicen explícitamente que no les interesa — agradecer y cerrar con dignidad

**Cuándo escalar:**
- Si responden con interés concreto → proponer demo de 15 minutos
- Si preguntan por precio → ver respuesta de precio arriba
- Si tienen dudas técnicas → ofrecer demo o llamada de 15 minutos

**Cierre digno si no hay interés:**
```
Entendido [Nombre], sin problema.

Si en algún momento cambia la situación o conocés a alguien en el sector dental que necesite esto — tené en cuenta la referencia.

¡Éxitos!
```

---

## Notas de uso

- **Follow-up máximo: 2 intentos.** Después de eso, sacar del flujo activo.
- **Personalizar siempre** con el número de consultas que mencionaron en la conversación anterior — demuestra que escuchaste
- **El demo de 15 minutos es el mejor conversor** — proponer siempre antes de cerrar una conversación sin venta
- **No presionar el precio** — quien pregunta el precio ya está interesado; quien no pregunta necesita más contexto
