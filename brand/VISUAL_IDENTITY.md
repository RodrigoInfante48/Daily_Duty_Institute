# Daily Duty Institute — Identidad Visual

## Paleta de colores

| Nombre | Hex | Uso |
|:-------|:----|:----|
| Teal | `#00e6c7` | Color primario, CTAs, acentos |
| Gold | `#FFB800` | Precio, urgencia, badges |
| Dark Navy | `#1a1a2e` | Fondo principal |
| Surface | `#16213e` | Fondo secundario, cards |
| White | `#ffffff` | Texto principal (sobre fondo oscuro) |
| Gray | `#9ca3af` | Texto secundario |
| Red Dim | `#ff6b6b` | Precio tachado de competidores |
| Green | `#4ade80` | Badges de confianza, garantía |

## Aplicación

- **Fondos:** Dark Navy (`#1a1a2e`) como base, Surface (`#16213e`) para cards
- **CTAs:** Teal (`#00e6c7`) para botones primarios
- **Precios propios:** Gold (`#FFB800`)
- **Precios competencia (tachados):** Red Dim (`#ff6b6b`)
- **Garantía/trust badges:** Green (`#4ade80`)

## Tipografía (web)

- **Headings:** Font bold, alto contraste
- **Body:** Sans-serif limpia, legible en móvil
- **Números/precios:** Bold, color Gold

## Reglas visuales

1. Dark mode por defecto — profesional, moderno
2. Contraste alto siempre — accesibilidad mobile
3. Menos es más — sin decoración innecesaria
4. Producto siempre visible — screenshots reales de Notion
